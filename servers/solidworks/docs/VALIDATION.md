# Проверка реализации

Дата: 16 октября 2026. Реальная установка: **SolidWorks 2025 SP1.1, COM revision 33.1.1**,
русский интерфейс, Windows 11 x64, Python 3.14.7, MCP SDK 1.30.0, pywin32 312,
Pydantic 2.13.5.

## Автоматические проверки

`python tools/run_tests.py` проверяет ограничения параметров и геометрии, выход за границы
рабочих папок, явную перезапись, конфигурацию, индекс и Unicode-поиск библиотеки,
сериализацию и принадлежность одному потоку, тайм-аут без повтора операции, отмену запроса,
межпроцессную блокировку операций, регистрацию и валидацию MCP-инструментов.

Итог для 0.1.1: 38 тестов, 37 пройдено, один пропущен из-за запрета создания directory symlink.

Проверка directory symlink может быть пропущена, если Windows не разрешает создавать
символические ссылки. Это ограничение тестовой среды, не подтверждение проверки junction.

## Регрессия подключения Claude, версия 0.1.1

В пользовательском логе первый процесс успешно завершал MCP-discovery. Затем дополнительные
процессы Claude для Cowork/Code получали `WORKSPACE_IN_USE`: версия 0.1.0 удерживала блокировку
всю жизнь первого процесса. В 0.1.1 блокируется выполнение отдельной операции в STA-потоке.

Проверено на изолированных временных папках без запуска SolidWorks:

- Три одновременно живых stdio-клиента проходят `initialize`, `tools/list`, `prompts/list`,
  `resources/list`, даже когда общая блокировка занята.
- Их задания переходят в `waiting_for_lock`, доступны через `sw_job_status`, после освобождения
  блокировки выполняются успешно. Тайм-аут ожидания не дублирует операцию.
- Два независимых процесса с реальным `StaActor` и тестовым CAD-адаптером выполняют операции
  в порядке start/end/start/end. Одновременного входа в адаптер нет.
- Общий журнал содержит полные JSON-строки, включая большие Unicode-результаты обоих процессов.
- После ошибки операции общая блокировка освобождается.

Тест воспроизводит схему подключений из лога Claude; повторное подключение в установленном
Claude требует перезапуска приложения пользователем, чтобы выгрузить старый код.

## Что пока не подтверждено интеграционными испытаниями

- Запуск на SW 2024 и 2026: целевые версии, отдельные установки для теста не использовались.
- Материалы из конкретной производственной базы `.sldmat`, `.sldstd` предприятия.
- BOM с производственным шаблоном и перенос размеров на сложный многовидовой чертёж.
- Многотельные развёртки, многостраничные PDF, сложные группы профилей и обработка больших сборок.
- Числовая точность фактического расположения вставленных компонентов и набор сопряжений.
- Автоматическая проверка соответствия полного комплекта ЕСКД.

Пробный PDF не является рабочим чертежом для производства: схема размеров и допусков
не назначена; материал не выбран, расчётная масса зависит от настроек модели/шаблона.
Сервер не объявляет эти требования выполненными. Для внедрения нужны утверждённые
шаблоны предприятия, технологические таблицы гибки и приёмка на каждой используемой версии SW.
