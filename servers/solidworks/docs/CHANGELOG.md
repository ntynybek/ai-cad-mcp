# Изменения

## 0.1.1 — 2026-10-16

- Исправлен `WORKSPACE_IN_USE` при запуске дополнительных MCP-процессов Claude для Cowork/Code.
  Несколько клиентов могут завершить подключение и MCP-discovery одновременно.
- Блокировка рабочей папки перенесена с времени жизни сервера на отдельную операцию в STA-потоке.
  Полный сквозной сценарий удерживает её до завершения всех своих шагов.
- Добавлено состояние задания `waiting_for_lock`; опрос заданий и MCP-discovery не ждут блокировку CAD.
- Записи общего журнала защищены отдельной межпроцессной блокировкой, в них добавлен PID процесса.
  Ошибка записи завершения операции не останавливает очередь.
- Версия сервера доступна в `sw_status`, ресурсе возможностей и `--doctor`.
- Добавлены проверки трёх MCP-подключений, двух процессов с общей очередью операций, целостности
  журнала и освобождения блокировки после ошибки. Общий итог: 37 пройдено, один пропущен.

После обновления полностью завершите Claude Desktop и откройте его снова. Существующая
конфигурация с `tools/serve.py` не требует изменений.
